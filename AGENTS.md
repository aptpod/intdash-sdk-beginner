# Repository hosting

- This repository is hosted on GitHub, not GitLab.
- Use GitHub terminology and workflows:
  - Pull Request / PR
  - GitHub Issues
  - GitHub Actions
- Do not use GitLab-specific terminology or tooling such as Merge Request / MR or GitLab CI/CD.
- Before any hosting-specific operation, run `git remote get-url origin` and verify that the remote points to `github.com`.
- Never infer the hosting service from previous conversations or other repositories.
